# University Park Lions Mobile

## v0.1.8
- Persistent member authentication restored from Expo SecureStore on app startup.
- My Account shows the signed-in member and provides explicit Log Out.
- Calendar and Newsletters use the configured UPLC API.
- Member, meeting, and poll rows are tappable and open detail screens.
- Poll detail supports authenticated voting through the WordPress mobile API.
- Awards are grouped into one recipient card with award names and years.
- Android versionCode 9; iOS buildNumber 9.
